Getting started

Run a scan.
Read the evidence.

Pickable scans public domains asynchronously and returns source observations as they arrive.

Use the website

  1. Enter a public domain on the Pickable home page.
  2. Wait for the scan to start. The interface shows progress and may display a partial report before every source finishes.
  3. Open individual checks and inspect the original source reports before making changes to your site.

Use the REST API or MCP

The REST API guide includes the OpenAPI document, request limits, and error responses. For agents, see the agent integration guide. MCP read tools and scan history use network peer scope; starting a scan by MCP is disabled unless the operator enables it and configures a key.

Queue and request limits

The worker processes one scan at a time and holds at most 20 waiting scans. Scan submission is also rate-limited: the default is 5 accepted scans per peer address per hour and 30 across the server per hour. The operator can change these limits with PICKABLE_SCANS_PER_HOUR and PICKABLE_GLOBAL_SCANS_PER_HOUR. A 429 response includes Retry-After; wait for that interval before retrying. These in-memory limits reset when the process restarts. Behind a proxy, the service uses the peer address it sees and does not trust forwarded-IP headers, so multiple visitors may share a per-peer limit.

Interpret the report

The report separates readiness and marketing-playbook results. A source can be unavailable, incomplete, or still running. Unknown, warning, and not-applicable checks are not equivalent to failure. The score summarizes measured checks using the report's scoring method; it does not verify a real agent journey or promise referral, ranking, or revenue outcomes.

Frequently asked

Does a high score prove an agent can complete a task?

No. A score summarizes available source observations. It is not an independent real-agent task test or a guarantee of traffic, rankings, or sales.

Are scan results available immediately?

Scans run asynchronously. Status can include a partial report while sources are still running. The report download returns 404 until a report exists.

Are scan history and reports private?

Scan history and reports are scoped to the caller’s direct network peer IP. This is not account authentication; clients behind the same proxy may share access. Do not submit private URLs or credentials.

Can I scan a private host?

Pickable accepts public domain names for public websites. Private hosts and network destinations are not supported.
