Pickable currently offers a free public demo. This page does not list commercial plans, paid tiers, or a service guarantee.

Current resource limits

Scans are queued and processed one at a time. Up to 20 scans can wait in the queue. The default scan rate is 5 accepted scans per peer address per hour and 30 scans globally per hour. Service operators can tune the per-peer and global limits with environment settings.

When a queue or rate limit is reached, the API returns HTTP 429 and a Retry-After value. Follow that value before retrying. Limits are held in memory in this single-process demo and reset on restart; a reverse proxy can make several users appear to share one peer-address limit.

What is included

The public demo lets you request a scan of a public domain and read scan status, history, reports, raw source results, and preview metadata. Those read endpoints are public. Do not submit private URLs, credentials, or confidential information.

Availability and outcomes

External sources and configured server resources affect completion time and coverage. A score describes available observations only. Pickable does not guarantee agent task completion, referrals, search ranking, or revenue growth.
